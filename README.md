# アイサポ Ver.2.2

Ver.2.1.5 を基準に、活動エリア権限・地図中心UI・党員/サポーター名簿取り込みを追加した版です。

## Ver.2.2 の主な変更

### 1. 活動エリアのアクセス制御
- 一般利用者（member）は `Users.areaId` に固定活動エリアを持ちます。
- 一般利用者には、自分の固定エリア以外の `Records` / `Contacts` をApps Script側から返しません。
- 支部管理者（leader）は自支部内の活動エリアを切り替えられます。
- 県連管理者・システム管理者は利用可能な全エリアを切り替えられます。
- 管理画面から一般利用者の固定エリアを変更できます。

### 2. 地図中心UI
- トップの登録数・訪問済・再訪のカードを削除し、「分析」へ移動しました。
- 地図の高さを拡大しました。
- 「党員・サポーターを優先表示」フィルタを追加しました。
- 訪問ピンに、名簿と紐づいている場合 `⭐党員` / `🟠サポーター` の印を表示します。

### 3. 名簿拡張 / Excel・CSV取り込み
Contactsに以下を追加しました。
- email
- memberType (`party_member` / `supporter` / `general` / `unknown`)
- lat / lng

管理権限のあるユーザーは名簿画面から `.xlsx` / `.xls` / `.csv` を取り込めます。
代表的な日本語列名（氏名、住所、電話番号、メールアドレス、区分など）を自動判定します。
ファイル全体を「党員」「サポーター」と指定して取り込むこともできます。

同一エリア内で `氏名 + 住所 + 電話 + メール` が同じものは重複登録をスキップします。

## 地図上の名簿表示について
Excelに住所だけ入っている場合、名簿一覧にはすぐ反映されますが、地図にピンを置くには緯度・経度が必要です。
名簿編集画面の「住所から地図位置を取得」で1件ずつ位置を保存できます。
無料のOpenStreetMap/Nominatimへ大量の住所を一括送信しないよう、Ver.2.2では大量一括ジオコーディングは実装していません。

## 更新手順
1. `gas/Code.gs` をApps Scriptへ上書きして保存。
2. Apps Script上で `upgradeV22` を **1回だけ** 実行。
3. Webアプリの既存デプロイを「新バージョン」で更新。
4. GitHubの `v2-dev` に `index.html` / `assets/` / `gas/Code.gs` / `README.md` を上書き。
5. ブラウザを再読み込み。
